# Ayo Berhitung! 🦄

Game berhitung untuk anak persiapan SD: mengenal angka → penjumlahan/pengurangan 1 digit → 2 digit.

Main: https://ahmadrisal.github.io/berhitung-anak/
Di iPad/Android: buka link di Safari/Chrome → "Add to Home Screen" → bisa dimainkan offline.

Cek soal: `node test.js` · Coba lokal: `python3 -m http.server` → http://localhost:8000
Setelah mengubah file, naikkan `VERSI` di `sw.js` supaya perangkat mengambil versi baru.
